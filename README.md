# .github — Quantium Crew, S.A.

Repositorio de configuración compartida de la organización. No contiene código de producto.

| Archivo | Para qué sirve |
| --- | --- |
| [`profile/README.md`](profile/README.md) | El README que GitHub muestra en la página de la organización. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Convenciones de ramas, commits y pull requests. |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Código de conducta (Contributor Covenant 2.1). |
| [`SECURITY.md`](SECURITY.md) | Cómo reportar una vulnerabilidad y manejo de secretos. |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Plantilla de pull request. |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Plantillas de reporte de error y propuesta de mejora. |

Estas plantillas se aplican por defecto a **todos los repositorios de la organización** que no
definan las suyas propias.
