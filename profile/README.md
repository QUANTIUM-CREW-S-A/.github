## Quiénes somos / About

Quantium Crew es un equipo de desarrollo panameño que construye **producto real**: aplicaciones
web, apps nativas de Apple, paneles de control, integraciones con servicios de terceros y
automatización de procesos internos. Trabajamos de punta a punta — diseño de datos, backend,
interfaz y despliegue — y entregamos sistemas que se usan a diario, no prototipos.

> *Quantium Crew is a Panama-based development studio building web applications, native Apple
> apps, dashboards, third-party integrations and process automation — end to end, from data
> model to deployment.*

## Servicios / Services

| Servicio | Qué incluye |
| --- | --- |
| **Aplicaciones web** | SPAs y PWAs en React + TypeScript, con modo offline, exportación de documentos y autenticación de dos factores. |
| **Apps móviles y de escritorio** | Aplicaciones nativas para iPhone, iPad y Mac en Swift + SwiftUI, con SwiftData, widgets y Face ID. |
| **Paneles y dashboards** | Visualización operativa en tiempo real: monitoreo de servidores, indicadores de negocio, reportes por sucursal. |
| **Integraciones y automatización** | Conexión con APIs de terceros, portales gubernamentales, pasarelas de pago y contratos on-chain; scrapers y tareas programadas. |
| **Backend y datos** | APIs REST en Node/Express y Python/FastAPI, microservicios con API Gateway y colas, PostgreSQL y Supabase. |
| **Despliegue** | Contenedores Docker, CI en GitHub Actions y puesta en producción. |

## Cómo trabajamos / How we work

- **Conventional Commits** y ramas `feat/`, `fix/`, `chore/`; `main` siempre desplegable.
- **Revisión por pull request** con plantilla propia y CI antes de fusionar.
- **Secretos fuera del repositorio**: `.env.example` versionado, credenciales nunca.
- **Licencia MIT** para todo lo que publicamos como código abierto.

Las plantillas de issues, pull requests y las políticas de contribución, conducta y seguridad
de la organización viven en este mismo repositorio.
